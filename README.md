# Jesse Trading Lab

Project based on the official Jesse project template.

This repository is intentionally separate from Miracolo Lab.

## Base

The initial structure follows `jesse-ai/project-template`.

## Local start

1. Copy `.env.example` to `.env`.
2. Run `cd docker && docker-compose up`.
3. Open `http://localhost:9000`.

We will develop this project incrementally, keeping each working stage reproducible through Git commits.
